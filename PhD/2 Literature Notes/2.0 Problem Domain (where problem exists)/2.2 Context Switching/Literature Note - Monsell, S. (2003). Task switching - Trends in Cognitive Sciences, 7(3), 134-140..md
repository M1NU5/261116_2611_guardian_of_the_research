# Key Point

- Introduces the idea of Task-Set-Reconfiguration, which is the time/effort/resources required to 'change gears in the brain'. Performance is better when a longer time has passed before returning to an uncompleted task. Is this due to that specific TSR recovering, so rotating around TSRs throughout the day may be useful when one must context switch?
