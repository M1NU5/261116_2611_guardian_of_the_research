>[[Meder, K., Jain, B. J., Plumbaum, T., & Hopfgartner, F. (2015). Gamification of workplace activities|(Meder et al., 2015)]] examines the concept of gamification under the following hypothesis:
>- Gamification refers to diverse types of users that use game elements with many different ways.
>- Gamification is used in order to accomplish a set of goals, as for instance the issue of assigning each user a game design element that will encourage him to accomplish goals.

>[!citation] Citation - Introduction
>[[Werbach, K. (2014). (Re)Defining Gamification - A Process Approach|(Werbach (2014)]] has developed a successful design process should include the following features:
>-  Define the goal behind gamification implementation
>- Outline the desirable user behaviour with the initial goal
>- Describe the target audience
>- Devise activity loops with emphasis on achieving progress and enhancing engagement
>- Do not forget the fun part
>- Deploy gamification efficiently with the use of the right tools
