
# Open Coding
This is a foundational component of [[Grounded Theory]] and developed by Glaser & Strauss (1978) in their book Theoretical Sensitivity.


## Types of Coding
- Template Analysis
## Step 1 - Identify Categories
- Go through the data openly without preconceptions
- Find similar content

## Step 2 - Abstraction (Instead of Description)
- e.g. for the example text of... 'I usually use TikTok to get the latest news'
- Instead of creating a category that 'describes' it as 'News', go up a level of abstraction to 'Information Acquisition'
- For each category, define 'dimensions' i.e.
	- Frequency - Number of content that fits into this category
	- Content
## Step 3 - Constant Comparison
- Are the codes being assigned consistently?


## Step 4 - Achieving Saturation
- Confirming that no new categories are needed
