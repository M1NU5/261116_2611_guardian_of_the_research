- [ ] **🧭 START HERE 03 — Plan your first research quest**
	  - [ ] Open your dashboard and identify or create a research project (**World**).
	  - [ ] Define a research goal (**Quest**) and one work package (**Mission**).
	  - [ ] Break the mission into two actionable tasks (**Objectives**).
	  - [ ] Add each objective to Kanban and link to its project note using `[[wikilinks]]`.
	  - [ ] Check the dashboard to see whether your project and tasks appear; if not, check how the dashboard is configured.
	  - [ ] Move this tutorial card to **Done**.
- [ ] **📚 START HERE 04 — Add your first paper to Zotero**
	  - [ ] Install and open [Zotero](https://www.zotero.org/) if needed.
	  - [ ] Add an academic paper and attach its PDF.
	  - [ ] Verify title, authors, publication year, DOI (if available) and PDF attachment.
	  - [ ] Read the abstract and note the paper's central contribution.
	  - [ ] Check whether your vault documents a Zotero import plugin and its setup; you will use it in Quest 06.
	  - [ ] Move this tutorial card to **Done**.
- [ ] **🖍️ START HERE 05 — Annotate using the 11-part literature skeleton**
	  - [ ] Read the paper in Zotero and highlight relevant passages, keeping page references.
	  - [ ] Categorise evidence using: **Problem; Constructs; Theoretical Lens; Mechanisms; Intervention; Context; Methods; Measures; Results; Limitations & Quality; Relevance**.
	  - [ ] Where a configured Zotero template maps highlight colours to categories, use that mapping consistently; otherwise use comments or tags.
	  - [ ] Add your interpretation separately from the author's claims.
	  - [ ] Leave unsupported categories empty; do not invent evidence.
	  - [ ] Move this tutorial card to **Done**.
- [ ] **📥 START HERE 06 — Import a Zotero paper as a Literature Note**
	  - [ ] Confirm the vault's documented Zotero import plugin is installed, enabled and configured, if one is supplied.
	  - [ ] Run the documented import command/template; if unavailable, create a Literature Note manually using the 11 headings.
	  - [ ] Check title, authors, year, citation key, Zotero link and source details.
	  - [ ] Check the 11 extraction headings and any imported annotations.
	  - [ ] Compare quotations, colours/categories and page numbers with the original PDF.
	  - [ ] Move this tutorial card to **Done**.
- [ ] **💡 START HERE 07 — Write your Literature Note's Key Point**
	  - [ ] Open the Literature Note created in Quest 06.
	  - [ ] Find the `## Key Point` heading.
	  - [ ] Write **1–3 sentences in your own words** explaining the question, principal finding/argument and significance.
	  - [ ] Example structure: *“This paper examines [problem] using [approach]. It finds/argues [main contribution], which matters because [implication].”*
	  - [ ] Distinguish the authors' conclusions from your own interpretation and add a source/page reference where appropriate.
	  - [ ] Reread the Key Point: does it make sense without reopening the paper?
	  - [ ] Move this tutorial card to **Done**.
- [ ] **🧠 START HERE 08 — Create a Zettelkasten concept note**
	  - [ ] Select one meaningful idea from your Literature Note.
	  - [ ] Create a separate **atomic concept note** explaining one idea in your own words.
	  - [ ] Link to its source Literature Note using `[[wikilinks]]`.
	  - [ ] Link to another relevant concept or research question, and explain **why** the two are related.
	  - [ ] Preserve citations so your interpretation remains traceable to the original paper.
	  - [ ] Move this tutorial card to **Done**.
- [ ] **🕸️ START HERE 09 — Explore Graph View and backlinks**
	  - [ ] Enable Obsidian's **Graph view** core plugin if necessary.
	  - [ ] Open Graph View or Local Graph for your concept note.
	  - [ ] Find the connections between your paper, concept and research question.
	  - [ ] Open **Backlinks** and follow a connection to another note.
	  - [ ] Add one **meaningful** link with a short explanation of the relationship.
	  - [ ] Move this tutorial card to **Done**.
- [ ] **🏆 START HERE 10 — Review your progress and complete your first quest**
	  - [ ] Return to the Dashboard and review your project, goals and progress, where supported.
	  - [ ] Check your Kanban board: have your tutorial cards moved into **Done**?
	  - [ ] From the Literature Note's **Relevance** section, identify one genuine follow-up research task.
	  - [ ] Create that task on your own research Kanban board and link it to the Literature Note.
	  - [ ] Record anything that needs configuration or improvement as a new task.
	  - [ ] Move this card to **Done**. **Achievement unlocked: Research Apprentice — First Quest Complete!**
